SuperDevSpace is a desktop app for macOS, Windows and Linux that turns the AI coding CLI you already pay for — Claude Code, Codex, Gemini CLI — into a team.

- **A manager agent plans the work** and hires workers for it.
- **Every worker runs in its own terminal and git worktree**, so several of them can change the same repository at once without stepping on each other.
- **You stay in charge**: steer from chat, answer the team's questions, and review every diff before it lands.
- **Your code stays on your machine.** We don't sell tokens — the agents run on your own CLI subscription.
